# Kawalkada

Zręcznościowa gra przeglądarkowa: prowadzisz szereg bohaterów, który sunie za przywódcą jak wąż. Bohaterowie sami atakują wrogów w zasięgu, a Ty decydujesz tylko o kierunku marszu.

## Jak grać

Otwórz `index.html` w przeglądarce (działa też na telefonie). Nie trzeba niczego instalować.

- **Sterowanie:** strzałki / WASD, na telefonie przesuwanie palcem. `P` lub `Esc` to pauza, `M` wycisza dźwięk.
- **Przegrana:** uderzenie w mur, w skałę albo we własny szereg kończy wyprawę. Wyprawa kończy się też, gdy polegną wszyscy bohaterowie.
- **Sztandary:** na każdej fali pojawia się sztandar nowego śmiałka. Najedź na niego przywódcą, a bohater dołączy na końcu szeregu.
- **Klejnoty** dają doświadczenie. Przy awansie wybierasz jedno z trzech wzmocnień.
- **Monety** zostają po wyprawie. W obozie (menu) odblokujesz za nie nowych przywódców i ulepszenia stałe.
- **Co 5. fala** to strażnik lochu: Kamienny Golem albo Licz.

## Bohaterowie

| Bohater | Atak |
|---|---|
| Rycerz | cięcie z bliska, rani też sąsiadów celu |
| Łuczniczka | szybkie strzały z daleka |
| Piromanta | wybuchające kule ognia |
| Kapłanka | leczy całą drużynę |
| Krasnolud | wirujący topór wokół siebie |
| Szronica | lodowe pociski spowalniające wrogów |
| Nożowniczka | grad sztyletów i trafienia krytyczne |

Postęp (monety, rekord, odblokowania) zapisuje się w pamięci przeglądarki.
